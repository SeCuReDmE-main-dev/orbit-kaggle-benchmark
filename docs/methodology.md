# Methodology

## Product decision and scope of the comparison

The original product question was which engine to select. The author subsequently decided to retain baseline, N and P as user-selectable representations because he found their qualities complementary while developing Orbit. That interpretation is a product decision; it does not convert a tied controlled result into a superiority claim. Baseline gives three-state evidence items; N exposes independent T/I/F sets; P adds declared scope/attribute rules. In the frozen implementation, baseline and N share evidence eligibility and equivalent decision logic on the measured cases. The `none` condition is a no-report experimental control, not a fourth product engine.

## Unit of analysis

The final target corpus is ten packets, each with twelve bounded source views and six questions. Six packets carry 36 synthetic specification references; four carry 24 real questions awaiting human arbitration. Common extraction is shared among four answer conditions, reducing variation from separately extracting the same source material. C plans two models, ten packets and three repetitions: 60 extractions and 240 comparative productions. Packet conditions execute in the retained order baseline, N, P, none.

A production yields six question decisions. Question decisions, production generations, packet comparisons, checkpoint events and assertion counts are different denominators. Historical C has 591 completed ledger records (60 extraction + 236 production + 236 interpretation + 59 packet); those are not 591 model generations. C4 has nine distinct completed records for four productions and one packet.

## Scoring

Synthetic decisions compare ADMIT, REJECT and HOLD to the authored specification references. Malformed/missing synthetic decisions are INVALID rather than silently omitted. Necessary HOLD, excessive HOLD and unjustified conclusions are counted separately. Real decisions retain unscored status until semantic and reference arbitration; exact quote occurrence does not certify support. Costs include available observations of failed attempts, preserve unknown components, and deduplicate identical restored observations.

The historical analyzer resamples whole packets for paired descriptive intervals (2,000 bootstrap resamples; seed 20261001). There are only six synthetic packet clusters. These intervals describe the observed sample and do not certify causal or population-wide superiority. The earlier exported aggregate belongs to 221 productions, not later final coverage.

## Context and native agent boundaries

D Provider uses the same twelve frozen original source views in both conditions, two models, two conditions and three repetitions. Twelve outputs were recovered. Three Pro Context-condition outputs did not read Context, so only nine met the protocol reading criterion. There were 148 attempts, 147 admitted operations and one twenty-first-operation refusal; the longest trajectory was 60.42 seconds. Semantic correctness and comparative score remain pending human review.

E planned 144 trajectories but failed its latest eight-worker qualification when worker 7 did not match the frozen release fingerprint. No current E model trajectory was dispatched. A later isolated HTTP 403 probe reported bot protection; the earlier mismatched native body was not captured, so exact causal attribution remains unresolved.

## Public reproduction scope

The synthetic development replay includes 36 specification cases and the frozen TypeScript engine. It is an adapted public replay harness, not an independent new benchmark result. The public package deliberately excludes raw real documents, raw model answers, operational credentials, private storage locations and full conversation transcripts. Provider model execution and any substantive remeasurement remain in Kaggle; package preparation alone is not benchmark execution.
