# Native Boolean pilot preparation

Upload `orbit-native-pass-fail.ipynb` into a **new native Kaggle Benchmark Task** notebook. Preserve the historical task and collection results. The Python source `task.py` contains the same cells, including a valid Python call to the official `%choose` magic. Select **orbit_native_pass_fail** as the main task after running the definition and planned model cells.

Requirements: native Benchmark Task mode, Internet enabled for the hash-checked official Node fallback if Node is absent, Kaggle Benchmarks SDK 0.6.1, Node >=20, exact Flash/Pro catalog IDs, and a fresh inspected free quota. The preflight refuses a missing native runtime, different SDK or either unavailable model; no silent model replacement or paid provider key is used. A kernel exposing a different SDK needs an explicitly reviewed environment/source identity before execution.

Native output is an explicitly annotated `bool`. True means every shape, six-distinct-question, reference-decision, named-source exact-quote, portable schema and eighteen shared-engine checks passed. Malformed/empty/duplicate/unknown model output and contract failures return False with recorded assertions and sidecar diagnostics. They are never retried. Transport/process/protocol failures raise exceptions; they do not become False model results. There are zero automatic retries. One provider attempt per model is planned; a technical error is retained and the other model is still attempted once. At most one manual corrective technical retry TOTAL may be considered after an identified correction and separate dispatch decision, never for invalid or False model output. Only one Boolean-result repetition is planned for each exact model. Raw hidden reasoning is not exported by the diagnostic code.

`contract.py` is the same pure validator embedded in the upload notebook and can support independently authorized fixture checks inside Kaggle. Syntax parsing during preparation is not a completed behavior test, model run or native upload. Diagnostic files are written only at runtime inside `/kaggle/working/orbit-native-pass-fail`. Their existence/counts must be recovered before reporting actual results.

The prompt and embedded engine bytes remain those of the six-question historical pilot. Strict validation/result semantics have a new identity in `manifest.json`; no old score, source or result is relabeled. Public synthetic references stay outside the model prompt. The exposed pilot is a transparent development check, not an independent hidden accuracy study.
